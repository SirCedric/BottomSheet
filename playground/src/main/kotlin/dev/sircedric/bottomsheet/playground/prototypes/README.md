# Prototypen

Ablage für die Prototypen der Wayfinder-Prototyp-Tickets (Host-Mechanik, Detent-Layout,
Nested Scroll). Ein Prototyp ist ein Composable in diesem Package, das von
`PlaygroundActivity` aufgerufen wird — Wegwerf-Code, der eine Design-Frage beantwortet,
kein Bestandteil der Library.

Dateibenennung: `<Ticketnummer>_<Kurzname>.kt`, z. B. `06_HostMechanics.kt`.
